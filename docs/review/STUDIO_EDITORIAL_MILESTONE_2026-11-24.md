## Why this design is different

This isn't an "AI agency" template. It takes the strongest design ideas from editorial engineering portfolios, evidence-first case studies and interactive product storytelling without copying another website's brand, proprietary composition or source code.

The design uses **self-hosted Archivo Variable** for clear technical and editorial headings, with a restrained **system serif** for select human-readable emphasis. There are no third-party font downloads, pretend command consoles, glowing AI brains, chat bubbles posing as real customers, animated particle fields, invented metrics or production screenshots.

## Design changes

- **Editorial opening:** compact dateline, large two-voice type, practical problem-solving copy, clear navigation, dark archival n8n project evidence (dated historical context, not current live status).
- **Evidence strip:** CEFA's exact November 24, 2026 database snapshot of 127 onboarded students, 10 groups and 113 non-deleted group chat messages. These are programme-specific counts.
- **Interactive project studio:** three selectable operating problems (cohort learning, restaurant order intake, security attendance), with a problem, engineering response, stage limitation, conceptual diagram and real case-study link. Works with keyboard and starts with meaningful HTML before JavaScript hydration.
- **Asymmetrical project sequence:** six feature cases arranged as a deliberate editorial series; large cases retain their architecture previews and accurate labels.
- **Engineering lab:** a different original SmartBook n8n screenshot, rather than repeating the hero's job-intelligence screenshot.
- **Method and contact:** fewer template sections, specific principles and a practical invitation.
- **Motion budget:** only lightweight transitions on meaningful targets; none required to reveal content; reduced-motion mode disables them.

## Do not claim

- The user's job-alert historical screenshot establishes current seven-source uptime.
- Client guard scale is verified application adoption.
- The newer restaurant management/kitchen/accountant dashboard or gateway payment processing is fully launch-certified.
- Elion's AI WhatsApp conversation viewer and same-number takeover are operational without connected provider tests.
- Unverified prospect/qualified-to-call totals.
